# Breakout Game

Juego tipo Breakout desarrollado con JavaScript y HTML5 Canvas.

## 🎮 Descripción

Proyecto web en el que el jugador controla una paleta para mantener una pelota en movimiento y destruir todos los bloques de la pantalla.

## ✨ Funcionalidades

- Movimiento de la paleta mediante las teclas de dirección.
- Rebote de la pelota contra las paredes y la paleta.
- Detección de colisiones con los bloques.
- Sistema de puntuación.
- Sistema de 3 vidas.
- Mensaje de victoria al destruir todos los bloques.
- Pantalla de Game Over al perder todas las vidas.
- Reinicio automático de la partida.

## 🛠️ Tecnologías

- HTML5
- JavaScript
- Canvas API
- Tailwind CSS

## 🚀 Ejecución

El proyecto está compuesto por un único archivo HTML.

Para ejecutarlo, abre `index.html` en un navegador web.

Las dependencias externas se cargan mediante CDN, por lo que es necesaria conexión a Internet.
